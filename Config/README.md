# Configuration data

Configuration will be stored in human-editable UTF-8 files. The first data format will be selected after the parser and Orbiter-era runtime constraints are confirmed. Avoid hand-editing generated save data.

Planned datasets:
- locations: celestial bodies, orbital regions, stations, and stable IDs.
- commodities: cargo IDs, mass per unit, category, and handling flags.
- markets: station inventories, price rules, and restock policies.
- vessels: vessel class profiles and cargo adapter declarations.
